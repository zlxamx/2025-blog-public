# 观影

这个星期去看了电影《蜘蛛侠：崭新之日》

看完之后，我思考了一个问题。

这部电影有没有观影门槛？自从蜘蛛侠回归漫威宇宙之后，它的观影门槛就明显上升了，虽然蜘蛛侠的基本人设都没有变，例如生活在皇后区、梅姨对蜘蛛侠的影响等等。

但随着蜘蛛侠和托尼·史塔克等人产生了越来越多的联系，蜘蛛侠的人物形象相比起索尼之前制作的蜘蛛侠系列要复杂得多。

一方面，小蜘蛛失去了梅姨和自己的女友MJ，这些都是传统蜘蛛侠人设中存在的内容，而另一方面，随着小蜘蛛在漫威宇宙里遭遇了越来越多的人和事，这些人和事对他个人的成长产生了剧烈的影响。

可以说，加入漫威故事线中的蜘蛛侠，早已和多年前传统的蜘蛛侠不同。

他的成长曲线更加曲折，一直到《崭新之日》的故事结尾，我才看到一个成熟的蜘蛛侠。

所以在我看来，《蜘蛛侠：崭新之日》这一部电影的主题就是**「成长」**。

网络上很多人说，这是部文艺片，文戏太多，很多人在电影院都要睡着了。

看完电影之后，再回想起这些评论，我觉得无奈又好笑。

无奈在，这个时代的观众好像越来越不会欣赏文戏了，他们渴望逼真的特效、激烈的冲突和眼花缭乱的打斗。

好笑在，这些观众口口声声说喜欢蜘蛛侠，却很少有人真正关心他的成长与蜕变。

蜘蛛侠是一个荧幕角色，但仅仅只是荷兰弟蜘蛛侠，就已经陪我这样的人度过了整个青春，对我而言，荷兰弟蜘蛛侠几乎可以说是一个活生生的人，就像自己的一位朋友一样，我看着电影里他的故事，听他说话，就像是在看一个相识已久的人。

所以我毫不认为《崭新之日》是一部文戏偏多的电影，相反，我认为，一部电影要推动一个人物的成长，就必须加以适当的文戏。而《崭新之日》的故事节奏在我看来，可以说是无可挑剔。

而那些在网络上说电影不好看的人，我其实蛮想问一句，他们知道二代黑寡妇[^1]是谁吗？他们看过《雷霆特工队》吗？他们中有多少人连「惩罚者」是谁都不知道？具体答案不得而知，但我想，所谓的观影门槛就在这其中。

漫威蜘蛛侠的角色成长是一个跨越了许多年的故事，参与并认识这个人物的成长就是它的观影门槛，这些年里连我们这些观众都早已和多年前不同，很多人甚至连自己都不关心，又何况是一个银幕人物。

但，这只是把《崭新之日》这部电影放在整个漫威宇宙时间线里来说，难道对于一个普通观众，就不能纯粹从电影的角度来评价这部电影吗？

当然可以，并且就连我也不能说这部电影是完美的，它确实有做得不好的地方。

对我来说，那就是剧本写得太好猜了，基本看了开头就能把后面的剧情猜个八九不离十。

但不可否认的是，对于互联网上那些针对蜘蛛侠文戏太多的言论，我只能说，他们应该大多都在观影门槛之外。

当惩罚者站在医院的窗口前假扮蜘蛛侠，彼得·帕克从容地从医院大门走进欢呼的人群，他停下脚步，看着那些呼喊着他名字的群众，对着一个小孩做出吐蛛丝的动作，我想这就是最好的结局了。

![](/blogs/zk21/d6937e2aa9268d12.jpeg)

如果要从剧情的冲击力上来说，《崭新之日》远不如上一部《英雄无归》，后者把三代蜘蛛侠同框的策划对于蜘蛛侠来说完全不亚于《复仇者联盟4》，但无奈创作团队的创作力和想象力都太过平庸，把蜘蛛侠塑造成了一个圣母心泛滥的幼稚角色，浪费了这么好的idea。

所以，看完《崭新之日》之后，我很庆幸蜘蛛侠没有一直走向歧途。


# 演唱会

这个周末去看了凤凰传奇的「吉祥如意」巡回演唱会成都站。

![](/blogs/zk21/0234dafc4a700361.jpeg)

二十年前那个智能手机还没普及的年代，凤凰传奇会想到自己二十年后还会这么火吗？小时候我听着《月亮之上》和《荷塘月色》的手机铃声长大，但那个时候我从来没想过，有一天我会坐在现场听他们的演唱会。

凤凰传奇绝对算是现在还在举办演唱会的歌手里面最独特的一对了吧？他们的听众完全不垂直，男女老少完全不挑，也不靠颜值吸引粉丝，如果非要说他们的吸引力是什么，那还真是才华。

其实仔细想想，连我这样生长在农村的00后，都对他们的歌耳熟能详，这已经足以说明他们的影响力，在那个网络媒体还未兴起的年代更是如此。

而或许又是因为他们的作品太过于深入下沉市场，导致有些人会觉得他们的歌有点过于接地气，说直白点，就是有点土。

但我觉得，这就是凤凰传奇含金量的最佳体现。

他们的歌唱起来朗朗上口，歌词简单但却意境悠扬。

「我像只鱼儿在你的荷塘，只为和你守候那皎白月光。」

「在你的心上自由的飞翔，灿烂的星光，永恒的徜徉。」

「乌蒙山连着山外山，月光洒下了响水滩，有没有人能告诉我，可是苍天对你在呼唤？」

「当梦想绽放出，耀眼万丈的光芒，红太阳，冉冉升起在远方。」

虽然购买凤凰传奇演唱会门票这件事，大多是因为互联网热度的原因，但在演唱会中和结束之后，我重新审视了凤凰传奇这个组合和他们的作品。

也许很多人get不到他们的艺术风格，但结束以后，我只想说，我从来没有见过从第一首歌第一句歌词就能开始合唱的演唱会。

我也从来没有听过这么整齐划一的合唱现场，歌手从来不需要引导听众，因为但凡听众会唱的，他们自己就会唱的。

在当今这个时代，凤凰传奇能够不靠颜值不靠垂直的粉丝流量成为诸多演唱会中人气最高的之一，说明他们的艺术是得到大多数人民认可的。

**人民认可的艺术，才是真正的好艺术。**

而这一点其实根本不需要证明，毕竟在用手机听歌还是个稀罕事的时候，他们就已经得到了市场的认可。

未来如果还有机会，我觉得不排除还会再来一次的。


# AI

盘点一下我现在的AI订阅

- SuperGrok heavy 
- Codex Pro 5X
- Kimi Allegretto
- Deepseek Api

7月份真是焦虑的一个月，一股脑地订阅了这么多AI，实际上现在token是多到完全花不完的程度，但思路卡住了，有力气也没处使。

文芽Seedraft其实本来已经是一个成熟的产品，但我在两个星期之前忽然脑子一抽，想到一个大胆的改变思路，所以想要彻底改造它，但实践起来，我发现这件事情比我想象中的要难很多。

过去的文芽Seedraft是一个基于固定流程和大量提示词建立起来的工作流，但经过我多番思考，这样的一个产品说它是个AI产品其实有点算不上，因为用户使用的自由度太低，比如想要和用户深度的讨论剧情，这是没有办法做到的。

而我决定把Seedraft打造成一个真正的Agent软件，在保持工作流的情况下，给予用户更多的自由度，这才是我对AI时代创作软件的想象。

我和几位朋友聊过我的思路，大的思路上基本都表示认同。

但要在固定的工作流上搭建出一个拥有相对自由度的Agent，对我来说谈何容易？我对Agent的设计一窍不通，只能依靠不断地询问AI来理清思路。

但是这一来二去，思路还是乱得不行。

上周我看到卡帕西[^2]的这样一段话：

>我发现一个跟大语言模型（LLM）打交道时挺有用的法子，就是来一次痛痛快快的长篇碎碎念。有时候，LLM需要更多“信息位”才能理解你到底想干什么，可你又懒得一个字一个字敲出来。这种时候，我就喜欢往后一靠，切到语音输入，然后啰里吧嗦地说上大概10分钟，乱七八糟什么都行，完全意识流。偶尔我会在开头先声明一句，比如“切换到语音识别了，错别字啥的见谅……”。有时候我也会把它变成几轮来回的小访谈。但我发现，LLM特别擅长从这些长长的、颠三倒四的碎碎念里重建出条理，而且它们对你那团乱麻似的思路的“回响”，往往比你一开始抛出去的要清晰得多。结果就是，你跟模型的“心灵融合”会变得更顺畅，从那之后需要纠正的地方也少多了。

![](/blogs/zk21/489daeb0fd924df5.png)

顺着这个思路，我做了一件事：和Codex打了个电话。

这还是我第一次和Codex打电话，给我的感觉是太拟人化了，会刻意模仿人的思考停顿，让我真的感觉像是在和一个人聊天。

我就把我对产品的设想，磕磕巴巴地一顿说给了它听，最后再让它提取和抽象我的产品设计，这样下来，Codex就帮助我理清了思路。

还有一件事：那就是一旦想到和产品设计有关的东西，立刻用语音输入说出来，说得越多、越详细越好。

就这样说了两三天之后，我把我说的所有内容全部发给了AI，然后告诉它这是我对产品的设想，但是我不会很多专业术语和名词，让它从我的内容当中试图去理解我的想法。

这样做的效果非常好。

然后再经过我和AI的多轮打磨和沟通，最后写出了一个详细的产品设计文档。

我现在发现，在做产品的时候和AI一轮一轮的沟通小细节，不如一开始就和AI沟通好，然后让AI一次性执行它几个小时，然后再Review两轮。这样做不仅质量看不出区别，自己的精力也省了很多。

所以要总结一句经验，那就是：所有对产品的设想都有一条是核心中的核心。

把这条核心做好了，其他的事情自然会水到渠成。当自己不知道怎么办的时候，就把自己内心对产品最原始的想法一字不差地记录下来，然后交给AI。

另外，从现在来看，最具有性价比的订阅还是GPT Pro，主要是因为Tibo太大方了。

下个月我会取消SuperGrok的订阅和Kimi，只保留Codex和Deepseek。

不得不承认的是，Code降价之后的性价比已经和DS差不多了……
