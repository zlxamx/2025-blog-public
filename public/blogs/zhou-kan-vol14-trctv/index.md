# 电影《镖人》

这周哔站上了春节档的电影《镖人》[^1]，趁着假期闲来无事，我就看了这部电影。

今年春节档的电影我是一部都没看，倒不是因为不好看，只是我这几年看电影的频率相比起学生时代可以说是断崖式下降。一方面是因为工作了，个人时间少了；另一方面是还要平衡锻炼、学习等许多要用在个人时间上的事情。

其实我几年前看过一次镖人漫画，已经记不清具体是什么时候了，只记得是在一个书店里，十分无聊，所以翻看了第一册，至于剧情我基本也忘得差不多了。

电影的武术指导是袁和平[^2]，他的作品可以说是封神，看得人麻了，例如《卧虎藏龙》《功夫》《一代宗师》，国际上还有《黑客帝国》《杀死比尔》，这都是当代影迷耳熟能详的名字。

演员上也是全明星阵容，有李连杰、梁家辉、张晋、谢霆锋这些老牌动作大咖，吴京、张译这些演员在他们面前都显得有些年轻。

看到李连杰出场的时候，我的内心十分感叹，李连杰是真的老了。我记得我小时候看他的《黄飞鸿》《霍元甲》《太极张三丰》《倚天屠龙记》，那时候的他是真的年轻；我又想起前段时间看的电影《捕风捉影》里的成龙大哥，岁月也写在了脸上。

我不知道像成龙和李连杰这一代演员，算不算是属于 00 后的记忆，但对于我来说，我小时候就是看他们的电影长大的，看着他们现在的样子，心中总有一种时代变迁之感。

再说回电影本身。动作戏其实没什么好说的，过年的时候网络上的评论就是这部电影的打戏很爽，而且是全程从头打到尾。事实也的确如此，但是对于我来说，这样从头打到尾的剧情其实并不吸引我。

对我来说，这样的电影，打戏是一部分，文戏也同样重要。文戏在一部电影中起到什么作用呢？在我看来首先是塑造人物，其次是推动剧情。因为只有人物立体起来，他做出的选择才能合理；一个人物做出合理的选择，就会推动剧情的发展，也不会缺少戏剧性。

而《镖人》的文戏太少，仅有的短暂几处文戏，在我看来也做得过于简略，对于人物塑造而言有些单薄。例如电影里刀马的脸谱是什么样的？财迷，爱自由，不好杀，这个人物的过往是曾经在朝廷做事，却因此失去至亲。

故事中谛听[^3]是站在刀马对立面的人，他们亦敌亦友：友，是因为他们曾经是要好的战友；敌，是因为当两人的人生同时遭遇重大变故时，价值观的差异让他们走向了对立。刀马追求「久在樊笼里，复得返自然」[^4]，而谛听则有点类似于《水浒传》里的宋江，但不完全一样——他想要刀马和他一起回到朝廷，恢复人生的秩序。

但是这种两人之间的世界观冲突，在电影里刻画得并不好。原因在于，经过改编的电影缺少大量的人物塑造工作，才会显得单薄。

看完之后，我想起我前几年看的一部电影，叫《投名状》，里面也有李连杰，但那时候他还是主演。这部电影上映于 2007 年，那时候我才五岁。

两部电影的打戏都很好看，但是我想，多年以后如果我再看到一部以打戏著称的电影时，我想到的应该还是《投名状》，而不是《镖人》。

原因就在于，前者在武戏精彩的基础上，充分地刻画了庞青云、姜午阳、赵二虎这三个角色，并在剧情的发展中利用三兄弟世界观的不同，充分地展示了人性的复杂和政治斗争的波谲云诡，所以整部电影才显得异常精彩。

我始终认为，有好的人物，才会有好的剧情，因为人物是推动剧情发展的关键，一个非常好的角色，可以掩盖一整部电影的不足。

这样的例子数不胜数。在国外，有《黑暗骑士》里的小丑，《沉默的羔羊》里的汉尼拔，《加勒比海盗》系列里的杰克船长，《阿甘正传》里的阿甘。

在国内，你能想到什么？我会想起《英雄本色》里的小马哥，《霸王别姬》里的程蝶衣，《大话西游》里的至尊宝。

我举这么多例子，就是想说明一点：一个被塑造到极致的人物，可以扛起一部本来就普通的电影。

所以我认为，《镖人》这样的电影，如果放到二十年前来拍，也许会更好看。当今时代的电影，对人物塑造似乎越来越不重视了。

前几年我非常喜欢的一部院线电影《封神》，导演是乌尔善。第一部看完之后我觉得非常不错，但没想到导演第一部赚了钱，第二部直接就不演了，所有人物全部崩盘，价值观崩塌，看得我想吐。

所以这可能也是我现在不太进院线看电影的原因了吧，因为信任值真的快消耗殆尽了。

再看今年到现在唯一一部爆火的电影《阿嬷的情书》，这部电影靠的不是某一个好到极致的人物，而是谢南枝、叶淑柔、郑木生等多个情感克制而真实的人物形象。

这也恰恰说明，在电影里，塑造人物不一定要有一个好到极致的角色，只要专心在做人物、讲故事，也能成就一部电影。

所以现在我很多时候不会再选择去电影院看电影了，去的话也是去看视听大片，或者是知名导演的新作，或者重映的老电影。

今年我只在电影院看了一场《迈克尔·杰克逊：巨星之路》，而现在来看，今年我应该还会去看《蜘蛛侠：崭新之日》《复仇者联盟5：毁灭之日》，其他的应该就都没啥兴趣了。

另外，我还想说一点。看到《镖人》的结尾，是诸多角色骑着马在落日下奔驰的画面，然后角色说着慷慨激昂的话，看起来有一种荡气回肠的感觉。

但我却觉得这种感觉其实很单薄，经不起推敲。

我已经不止在一部电影里看到这样写意式的结尾，但最成功的应该还是姜文的《让子弹飞》。我也不知道这种风气是从什么时候兴起的，但我想说，一个荡气回肠的结尾不是只靠一个庞大的场景和镜头就可以做到的。

这样的结尾往往是整部电影的情绪挤压到最后，通过一个借物喻情的手法来释放观众心中所有积压的情绪，这才是荡气回肠的由来。

[^1]: 《镖人》：漫画家许先哲创作的长篇武侠漫画，以隋末为时代背景。

[^2]: 袁和平：香港著名动作指导、导演，业内有「天下第一武指」之称。

[^3]: 谛听：原为佛教中地藏菩萨的坐骑（神兽），传说善辨真伪；此处为《镖人》中的角色名。

[^4]: 「久在樊笼里，复得返自然」：出自东晋陶渊明《归园田居·其一》。
