# AI

短短一两周时间内，我接连脱坑了Codex[^1]和Claude Code。

原因无它。Codex限制了我的账号登录权限，要求我在登录时使用手机号接收验证码验证。

当年ChatGPT横空出世的那个月末，我就注册了OpenAI的账号，那时候应该是在网上随便找了个接码的平台，用了一个印尼的手机号验证了，现在再让我用几年前用过的手机号验证一次，属实是有点搞人。

所以没办法，我的Codex账号没了。以往这种情况，一般来说我等上几天，就会自动恢复正常，不需要验证，然而现在已经半个月了，情况还是依旧。

时间一长，我也就接受现实了，只好弃坑了。

再说到Claude Code，与Codex相反，这款在国内互联网号称所有人的严父的AI，以封号疯狂著名的A社[^2]，从未对我的账号做过什么。直到我决定不再使用Claude，我的账号依然安然无损，甚至连订阅都还没有过期。

而我放弃Claude的主要原因，就是因为前段时间网络上A社所暴露出的监控中国人的事件。

A社在Claude植入监控，通过各种方式来判断一个用户是不是中国人（甚至会识别你的Emoji渲染方式）。

这是赤裸裸的歧视和针对，是典型的纳粹行为，该事件触及我的底线，所以我决定不再使用Claude的产品。

沉寂了半个月以来，我使用AI的频率也降低了很多，其主要原因是因为离开了GPT和Claude两员大将之后，我陷入了无AI可用的地步。在过去，我几乎只使用这两款AI产品，而国内的大模型，除了Deepseek，其他的包括Kimi，小米，GLM之类的，我都只是浅尝辄止，没有深度使用过。

而最近两天，我又订阅了一个新的服务——Cursor。

原因是在网上看到Grok 4.5模型的能力和性价比都相当不错，并且不会封号，我想着我现在一个AI模型都没有订阅，于是就抱着试一试的心态去接触了一下。

原本还在担心账号风控问题，结果一进Cursor发现居然可以用支付宝直接订阅，我释怀地笑了。

不过实际上，目前下来我的使用体验不是很好。

据传，Grok 4.5的工作速度很快，但我这两天使用下来，却觉得太慢了。例如今天早上我跑了一个有8个Task的任务，一般来说这样的任务3-4个小时，Codex就能跑完，可是Grok却跑了整整一天...当然，也许是因为中途莫名其妙的网络冲突中断了。

其次就是，我还发现，我没有选择Auto，自己锁定了Grok 4.5模型，但在执行任务的时候，系统派送给每个Agent的模型却不一样，有Composer 2.5、GPT 5.6、Sonnet 5，搞得我云里雾里，根本不知道是什么模型在执行我的任务。

再其次就是Cursor的软件使用体验不如Codex和Claude。在风格上 Codex和Claude大相径庭，前者比较新潮，后者比较复古，但他们在基础体验上都挑不出毛病，但Cursor在使用的时候总会莫名的卡顿，并且经常使用Command + Q都没办法关闭软件哈哈哈。

最近文芽Seedraft[^3]项目还在不断的打磨中，[我本来想注册一个Seedraft.com](http://我本来想注册一个Seedraft.com)的域名，但是不出意外已经被注册了，所以只好另注册了一个域名，也许以后能用。

域名这个东西，不贵，先注册着，也许以后就用到了。

# 打字

现在这个时代，还有必要练习打字吗？

在想这个问题的时候，我还想到一个问题，现在这个时代，打字不熟练的人还有多少呢？

在我八九岁的时候，家里有一台方脑壳电脑[^4]，算是比较早期的计算机样式了，我记得那时候看过一个电视剧，叫什么不记得了，主角是一个小孩，有一集他想要体验大人的世界，穿上他父亲的POLO衫出去找工作，其中一个就是打字员。

这说明在以前，打字熟练都是一份可以领到工资的工作。

但是计算机技术发展到今天，打字早就已经不是一项值得炫耀的技能了。

我的弟弟今年初中毕业，过完这个暑假就要去职业中学上学。我给他报名的是一个新型的理工科专业，未来少不得要和计算机打交道。

昨天我找了一个打字网站（[dazidazi.com](http://dazidazi.com)），让他测试他的打字熟练度，结果也是不出我所料，他基本只会用两只手指打字，键盘也不熟悉。

我记得我八九岁时，我的舅舅也督促我练习打字速度，那时候我觉得不以为意，但后来我的确在十几岁的时候打字速度就蛮快了，只是那时候我也不知道熟练打字有啥用。

要拿到现在来说，打字速度快有用吗？语音识别这么方便，Typeless[^5]更是革命性的软件。对此我只能说，**可以不用打字，但不能不会打字**。

如果说现在是AI时代，那么目前键盘还是接入AI的主流方式，反之，键盘也是接入计算机，和计算机交流的主要方式，想要访问网页，写文章，都要通过键盘来操作。

而我弟弟的计算机基础也相对薄弱，目前我想让他学一些关于计算机基础方面的理论知识，他可能会觉得枯燥，所以我想，就让他从打字练起吧。

把键盘摸熟了，也算是有所长进。

# 卖车

我有辆闲置的公路自行车。

之前我把这辆自行车的牙盘拆下来给了我的朋友，让他装在他的另外一辆车上卖掉了。

现在我要卖这辆车，就缺少牙盘了。实际上牙盘这个东西，一点儿也不贵，在闲鱼花一百块钱就可以买到一套。

但我因为懒得折腾，就准备把没有牙盘的车低价挂在网上卖了。

可是没想到的是，我卖了两个多月，都还没有卖出去，无一例外，这些客户都觉得没有牙盘，接受不了。

看来大部分人还是想买一辆拿到就可以骑的整车。但还有些人会认为，就算后面再配一个牙盘，也没有原装的好。

这是我觉得有趣的地方。如果说是买手机这类电子产品，肯定是要全原装非拆修的，但是自行车这个东西，为什么会有「原装思维」呢？

在我看来，自行车无非就是一堆零件拼在一起，只要是通用标准生产的零配件，都可以直接用。我认为这和理解一件事物的方式有关，很多对自行车不了解的人，就会把自行车当做一个整体来看。

而了解自行车的人，就可以把自行车拆散来看，牙盘、曲柄、飞轮、车架、变速器等等，多个组件组成一个完整的自行车系统。

自行车是这样，还有很多事情都是这样。例如写作这件事情就是这样，原来以为写作就是想到什么就写什么，事实差不多也的确是这样，但在想到什么就写什么背后，还藏着不少东西。

比如阅读。不管是阅读什么，严肃的文章也好，社交媒体也罢，本质上阅读是一种信息的输入，写作者是需要不断的输入，刺激和整理自己的思维来不断尝试写作的。

比如素材的积累。有时候，遇到好的句子和观点，就会记下来，所谓好记性不如烂笔头，很多时候摘抄过的内容，要比只是读过一遍的内容要记得牢很多。

《剑来》[^6]里，陈平安遇到眼前一亮的句子，会一笔一划刻在竹简上，时不时拿出来晒晒太阳，翻拣重读。

**把写作看作是一个系统**，阅读和素材的积累就是支撑这个系统的主要部分，当然还有其他，此处只是举例，不做过多叙述。

**用系统性的思维看事情**，好处是可以把一件笼统的事情拆解成一个个组成部分，就像学习一门知识的时候，总会有人说：你得先搭建一个知识框架。

但其实也有坏处，那就是如果处处都用这种思维看事情，有时候就会错过很多有趣的东西，让人觉得古板和累。

最后我还是自己在闲鱼上花不到一百元买了一套牙盘和曲柄，装上之后今天当天就把车卖了出去……并且价格还比我之前挂的价格高出好几百元。

哈哈，有时候自己稍微为别人折腾一下，就能省下好几百元，可是大多数人都不会这样想。

# 功夫女足

今天去观看了周星驰的新片《功夫女足》

以前我不觉得周星驰的喜剧有一种独特的风格，但今天之后，我得承认，周星驰的确有一套自成一脉的喜剧风格，就是那种一两句台词，一个简单的套路，马上就能看出这是周星驰电影的风格。

《功夫女足》里大多数演员都是现在耳熟能详的。迪丽热巴、张小斐、张艺兴，这倒是让我觉得意外，所以一开始看到这些演员用周星驰式的表演方法在演戏的时候，还觉得有点不适应。

这可能也是我电影前半个小时觉得电影极尬无比的原因，演员们都在用一种语速极快、语气夸张的方式说台词，让我觉得有些别扭，但后来我回想了一下，如果把这些和周星驰巅峰时期的那些电影来相比较，就发现都说得通了。

尤其是张艺兴这个师叔公的角色，我想就是完全为周星驰写的，如果年轻的周星驰本人来演这个角色，肯定就爆了。

总体来评价这部电影，我在豆瓣上打出了三星的评分。

这是一部极具周星驰风格的喜剧，相比起他的上一部电影《新喜剧之王》，这一部的诚意要好很多，并且电影里有心思的小巧思比较多，我想我还是领会到了一些，例如其他国家队球员的技能设计，与他们本国文化高度相关。美国人信仰科学，日本人的中二热血等等。

扣分就扣在，剧情设计太简单了，我全程都能猜到剧情走向，比如师叔公唱黑脸之后反转，结尾张小斐的奋力一击结果是装腔作势，这些内容都太好猜了。

还有一点就是我刚才说到的，张艺兴的表演虽然算不上差，但可惜周星驰的喜剧形象早就深入人心了，我都能想象周星驰来演这个角色的画面和台词会是什么样的。

最后还有一点。这部电影给我的感觉就是，星爷是还在做自己没错，但不知道是因为什么缘故，让我总觉得，现在的一切都只是对过去的怀念和模仿罢了。

就像香港电影的黄金时代早已过去，星爷也已经满头白发，不复当年青春年少了。

在这个电影行业萎靡不振，AI技术大行其道的今天，又有多少人能够数十年如一日的践行自己的艺术理念呢？

**你可以说周星驰的电影没有当年好看了，但绝不能说周星驰失去了初心。**

只要是看过《功夫女足》的人，都知道，这是这么多年来，最具周星驰血统的一部电影了。
