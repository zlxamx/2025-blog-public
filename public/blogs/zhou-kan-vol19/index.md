# 体育

七月，暑假，夏天。工作这么多年以来，夏天早已经不像大学时期那样充满活力了，但不可否认的是，夏天就是一个生命力与活力并存的季节，有生命力的人在这个季节会尽情地挥洒汗水，而没有活力的人，只要稍微靠近一点，也会被这个季节所感染。

而七月，对我来说，可以说是体育之月，因为多场世界瞩目的体育赛事都在世界各地举办着，例如美加墨世界杯、环法自行车赛、英雄联盟MSI季中冠军赛、EWC电竞世界杯[^1]等等。

而在这些比赛里，除了美加墨世界杯不是我的关注重点之外，另外三个我都有关注，那么在过去的一周里，都发生了什么呢？

## MSI和EWC

我看英雄联盟比赛已经很多年了。而今年的情况与前几年不同，LPL[^2]的BLG战队在第一赛段夺得全球先锋赛[^3]冠军之后就备受瞩目，国内的粉丝都盼望着他们拿下MSI冠军，再次证明自己。

然而，截至今天，不论是MSI还是EWC，都已经结束，其中前者以BLG 2:3 负于韩国战队HLE遗憾收场，而EWC则是以八强的成绩草草结束。

这意味着，整个LPL的第二赛段国际赛之旅就此收场。

然而，如果运动员在赛场上奋力拼搏，最终落得了一个遗憾的结局，对于赛区的观众而言，尚可接受，然而事情在于，有部分选手在赛场上没有很好地贯彻竞技体育的精神，存在自负、耍脾气、装高手等现象，这让很多赛区粉丝都无法接受，也包括我。

而BLG的上单选手Bin，缺乏团队精神，不仅导致比赛频频失利，同时也让团队内部氛围紧张，从场内到场外而言，这都是一支战队的不稳定因素。

从观众的角度来说，比赛的失利固然是让人难过的，但更让人觉得灰心的是，支持的战队和选手并没有良好的大局观，因为自己的性格和一己贪欲输掉了比赛，并且输得很丑陋，这才是让人真正心灰意冷的地方。

反观EWC的韩国DK战队，俱乐部连工资都发不出来，几位选手自己自费参赛，最终获得了EWC冠军，让全球观众为之动容和喝彩。

这样的故事在LPL有多久没有出现了？如果是常规赛，今年第二赛段的涅槃组集体飞升[^4]大概是这样的故事，而如果是世界赛，那我想至少也要追溯到EDG夺冠[^5]那一年了。

奥林匹克精神两条。第一条，全力争胜。第二条，要有风度接受失败。

作为职业选手，选择这个职业，胜负就是每天都要面对的东西。

如果结果不尽如人意，当观众从选手的发挥中看到了他们真的在认真竞技，一切都是浮云，就像美加墨世界杯中的佛得角[^6]，即便淘汰，也赢得喝彩。

可是对于英雄联盟电子竞技来说，我认为之所以很多人都无法认可电子竞技是一项运动，就是因为太多运动员（选手）的身上，找不到奥林匹克精神吧。

## Le Tour 环法自行车赛

环法自行车赛作为三大环赛[^7]中人气最高也最经典的赛事，在自行车圈有着非同凡响的地位，我从去年开始看环法，今年是第二年。

其实看到第二年，也只能算是刚刚入门，很多车手的名字熟悉但是并不认识脸，但是只要记住谁叫什么，在哪个车队，就不影响看比赛了，毕竟每个车队的主要车手就那么几位。

例如在我看来，2026环法就关注那么几位车手：波加查、温格高、赛沙斯、艾菲内普尔，还有我比较喜欢的犀利哥就行了。

而要说看点的话，其实还蛮多的，我可以大致罗列出几条：

- 今年温波大战会以什么结局收场？
- 赛沙斯能不能在今年环法证道？
- 艾菲内普尔到底有没有Ball？

这三个看点的精彩程度是从上到下排布的，然而谁也没有想到，最具看点的温波大战，在昨天就已经落下了帷幕。

威斯玛车队的总成绩车手、主将——温格高在比赛中出现了严重摔车，当场退赛。

自行车比赛一向是风险较高的比赛，多年来不乏车手在此丧命，摔断胳膊腿更是常见的事，但对于观众来说，一次摔车往往就发生在那么几秒钟之间。

自己期待的内容还没有来，车手就因为出现了意外而退出了比赛，我想很多观众对此事都是没有实感的，甚至自己的脑子还停留在幻想温波大战的画面，后知后觉才发现。

温格高已经退赛了。

对此，这次环法最大的看点已经下线。对我来说，我不是谁的粉丝，关注比赛只是享受一种别样的激情，但看见一员大将落幕，还是不由得惊讶。

希望温格高能够好好恢复，继续回归赛场吧！

# 观影

## 《喜剧之王》

上上周看完《功夫女足》之后，这周末我重温了一遍周星驰的《喜剧之王》，这算是周星驰的电影里我最喜欢的几部之一了。

只是没想到，时隔多年再看这部电影，会有那么多感触。

我觉得以前的老电影，尤其是港片，都有一个共同特点，那就是不会企图在一部电影里讲太多的事情，也不会想在一部电影里树立太多经典人物。

《喜剧之王》探讨的主题很简单，那就是爱情。虽然影片里用大量的桥段来表达尹天仇是一个壮志未酬的演员，但这些剧情的本质都是为了后续的升华而准备的。

“喂！你说要养我，是不是真的啊！”

“是啊！”

“你没有骗我？”

“没有啊，等着你呢。”

这两段对白，是周星驰对爱情的崇高敬意，因为对于尹天仇来说，出演电影的男主角，不仅是他的梦想，也是权利、资源、名利的诱惑。作为一个00后，当柳飘飘喊出那句“喂”的时候，我的心已经凉了半截，因为我总觉得剧情的走向应该是偏讽刺人性的：尹天仇没有回答，乘着车从此远去，只剩下柳飘飘独自一人。

但让我完全没有想到的是，尹天仇毫不犹豫地说他是真的想养她，那种感觉，没有一点点虚假。

或许是在现代社会生活太久的原因，总觉得像这样的情节都是艺术化手段罢了。

但相比起艺术化手段而言，我更认为在那个年代，爱情真的可以做到这么毫不犹豫，这样真挚。

只是这种真挚的情感，对爱情的尊敬化作了一颗子弹，在二十多年之后击中了我。

电影最后，柳飘飘织着毛衣，等着尹天仇回来。

尹天仇回来之后，柳飘飘叽里咕噜说了一大堆台词，说什么就算是跑龙套你也要养我，然而尹天仇什么都没说，只是说了一句：

“柳飘飘，我爱你。”

无需多言。

只是这部电影不知道为什么在最后莫名其妙加了一段警匪枪战的剧情，很割裂，就像莎士比亚写《维洛那二绅士》[^9]，把兄弟反目最后莫名其妙写成阖家欢结局一样离谱。

我无意去寻找这背后的原因，故事嘛，就是这样，有时候我们只关注自己想关注的。

## 《爱在黎明破晓前》[^10]

我想当今时代很多人都会看不下去这部电影。

开往法国的火车上，一个美国男人和一个法国女人因为一对吵闹的德国夫妇而结缘，然后他们就在餐车里聊了一路。

整个故事唯一具有戏剧性的地方，就是男主在本应该下车的车站邀请了要去巴黎的女主一起下车，在陌生的城市里继续聊天，第二天一早他坐飞机回到美国，她则再坐火车前往巴黎，而女主还同意了。

整部电影就是两个人在一座陌生的城市漫步，然后聊天。

是的，一直聊天，整部电影一个小时四十分钟，两个人一直在聊天，聊各种话题，包括但不限于自己的父母、祖父母、曾祖父母、自己的前男友、前女友，自己会对什么事情不爽、又喜欢什么事情、女权主义、哲学、音乐、文学、历史、传播学、媒体等等。

看完之后，我只能说，一个人如果能和自己这样聊一整天，又怎么能不爱呢？我回想我自己，且不说和自己的女友，我至今为止没有和任何一个人有这样深入、无话不谈的聊过天。

在看电影的时候，我甚至在想，这不是中西方文化差异？真的有中国人可以和别人聊这些东西吗？和别人聊现代人的灵魂可能是古代人灵魂的一个碎片？

中国人的羞耻心是一等一的重。即便在改革开放以来，在经济和文化上都接受了西方的冲击，但有些文化上的差异，在短短一两代人之间还不足以抹平。

**当今这个时代，每个人都是一座孤岛。**

有一个人能在自己感到寂寥之时寒暄几句已非一件易事，如果真的能够遇到像电影中这样能够敞开心扉畅谈一整天的人，那么我一定要和他做很好的朋友，甚至也像故事中的男主那样爱上对方。

和《喜剧之王》里那种义无反顾的爱情一样，《爱在黎明破晓前》同样给了我一种非现实的冲击感，这种冲击感不仅来自于艺术，更来自于时代。
