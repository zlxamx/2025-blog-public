# 从端午节说起

现在我终于有时间坐在电脑前认真地写作了。最近一段时间，我真的是太忙了，工作上，我有很多麻烦事要处理，直到现在我也只处理好了最棘手的事情，还有很多不那么棘手但却嗷嗷待哺的事情正等着我去临幸。

所以今天是周一，我来补写上周的周刊。

不过故事还要从端午节假期开始说起。

端午节当天，母亲回了老家去看望外公外婆，我就和嘉华还有子雨一起约定了出去玩。

我和嘉华是初中同学，但子雨却不是，他是我和嘉华在高中毕业后找的一份暑假工认识的工友，说是工友，但实际并没有一起劳动过，那份工作就是在大学里当招生老师，招揽非全日制学生。

在培训的时候我们住在一个宿舍，没事儿就一起打王者荣耀，这算是我们最大的交集了，后来培训了几天，我们都觉得这份工作不太好，就在群里一人甩了一个「电子竞技繁忙，告退」的表情包，天还没亮就收拾东西提着箱子跑路了。

后来除了子雨买电脑的时候咨询了一下我，我和他基本就没什么联系，但是奇妙的是，他和嘉华的关系却一直保持了下来，我回到四川之后，三个人的交际又莫名其妙多了起来。

有时候男人之间的友谊就是这样，因为一句话，一件事就缘起，还能持续多年。

最关键的是，我们三人其实差别还挺大。我大学学的物联网工程，典型的工科，而我最大的爱好是看书写作；嘉华大学学的是康复护理，最大的爱好是打游戏；而子雨是最特殊的，他是我们之间唯一一个还没毕业的，他说：「如果我找不到工作的话，就只能去读博士了。」哈哈，虽然不知道读博士是苦差还是美差，但对我一个打了四年工的社畜来说，这话听着还是有点抽象的。

那天上午，我们相约一起去参加「崩坏：星穹铁道」的一个叫做「夏日萤火」的活动，是这游戏里的一个叫做「流萤」的角色的个展，子雨刚好很喜欢这个人物，我们就去凑了热闹。

可是因为我们到得太晚（九点半算晚吗），最后队伍大概还有十几米的时候，所有的物料都发完了，此时时间已经来到了十二点，相当于我们白白排了一上午的队。

吃了午饭之后，我们陷入了虚无，想着下午去哪儿呢？

最后我们做出了一个合理的选择——上网。

上网这件事，我们也有差异。要说玩网络游戏，虽然子雨和我跟嘉华年龄都差不多，但是玩的游戏却不同。

我属于那种什么游戏都不玩的人，硬要说玩，那就是能玩玩英雄联盟；嘉华也是一样；但是子雨就不一样了，他是大学生，玩游戏的环境和我们不同，他不仅要玩英雄联盟，更多的时候还是在玩三角洲行动，或者瓦罗兰特。

这些都是现在非常风靡的游戏，但我和嘉华都不玩 FPS 游戏，没办法，子雨就和我们玩了一下午的斗魂竞技场。

是的，就是玩了一下午斗魂竞技场。

回来之后，我有些恍惚。三个男人休息日到网吧去打一下午英雄联盟，现在听起来这多少有点复古了，因为以前我们都是想开游戏就开游戏的人，而如今这却成了在相聚时才能拿来解闷的项目。

打完之后，吃个晚饭，然后各自回家。

我回家继续研究我的项目，嘉华继续回去玩怪物猎人，子雨继续回去为他是读博还是找工作而发愁。

虽然我们之间有诸多不同，但是聚在一起时总能相谈甚欢，我和嘉华都有健身的习惯，子雨没有，有一次带他去健身房，发现他连下蹲都不能流畅地蹲下去，于是就教了他回家靠墙静蹲的方法让他改善一下他的下盘。

你看，虽然我和嘉华不会因为读不读博士而烦恼，但还是有东西可以影响子雨的。子雨也是一样，子雨是我现实中交往的唯一一个学生了，并且有望成为我现实交往中认识的唯一一个博士，除了经常听他聊实验室趣闻之外，我还可以经常借用他的学生身份获得各种软件、电子产品的学生优惠。

子雨兄，你可千万要读博士啊，不然我缺的学生优惠这一块谁给我补啊！

# 工作

最近工作真的太忙了，但忙前忙后，其实主要就是围绕着两件事情在忙，因为一直围着这两件事转，其他工作也顾及不了了，从而堆积了起来。

熟悉我的读者朋友应该都知道我是做医疗器械售后工作的，就是给医院修设备。

修设备有什么好麻烦的呢？不就是设备坏了去给它修好就行了。

话是这样讲，但是售后工作不只是修机器这么简单，在许多方面都要做到八面玲珑。

我修机器的技术其实还行，基本上我经手的故障短时间内都不会二次出现，但是麻烦的事情不在于我不能修好，而是出现在以下两个方面：

- 这个问题不是我能解决的。
- 问题一个接一个，每天都不重样。

很糟糕，但是很现实，这两种情况在同一时间被我遇到了。

第一，这个问题不是我能解决的。什么问题是像我这样的现场服务工程师解决不了的呢？那就是软件问题，最近在都江堰上了一台设备，这台设备硬件上是很成熟的，但是却用上了一个新软件，这个新软件对比以前的软件设计看上去好看了些，但是确实外强中干，全是 BUG，连最基本的技术文档都不齐全。

遇到这种情况，我就只能一个一个问题与公司交流，然后一个个处理，但问题麻烦在，这个项目的负责人程序员之前突发了脑溢血，现在每天都要去医院做康复，我上午发一条消息，一个小 BUG，可能都要等第二天才能得到解决。

当效率降低的时候，这样的软件的不成熟性就会被无限放大。

所以我选择了搁置这件事情，把它往后拖。

然后去处理另外一件麻烦事，也就是上述的第二种情况。

一台新设备，刚到医院开始启用，用了十天坏了六次，六次都不重样。

这台设备现在在全国上市的范围极小，使用客户也很少，我这家客户可以说是全国第一家启用的，我这个做售后的工程师也是跟着享福了。

最近半个多月以来我几乎天天都在这家医院，每天搞得身心俱疲，这也是我最近一段时间以来完全没有精力用来写文章的原因。

实际上这些故障都是小问题，每一个我都能解决。但真正的问题在于，仪器的故障能修好，用户心里的疙瘩能消掉吗？在这之前，这家医院用的另一台设备在我折腾了半年之后才彻底稳定，现在没过多久，上了一台新设备又开始频繁地坏，原本还没有消失的疙瘩现在又长出了一颗新的。

最后我因为问题实在是太多了，就让公司派了一个技术来支持一下市场，结果没想到我请了个大爷来。

这个公司来的同志，不仅技术能力太差，连和用户妥善交流的能力都没有。

每次一出问题，他修不好，我就又要去医院修，原本就很忙的局面导致我现在每天还要两头跑。

所以面对这样的工作，我怎么会不心灰意冷呢？

我是真的劳累了，这位钦差大人来了四天，我四天都在医院。

一个故障让他检查半天，他说弄不好，然后我去了，发现是他根本不了解仪器的运行原理，在错误的地方调了半天，能修好才怪，我只需要五分钟不到就把问题解决了。

以前我从来不觉得自己的技术能力有多强，但是在对比之下，我不得不承认，我对问题的分析和研判能力还是挺强的（必须夸自己一句，不然真顶不住）。

今天我又在医院忙活了一天，算是把这件事情稳住了，未来几天还不知道要发生什么。

# 中考

成都中考今天出成绩。我弟考了 310 分。

在出成绩之前，我看了好些学校，但是因为分数没有下来，完全不能确定报什么学校，因为我弟的成绩本身就不咋好。

今天上午出成绩的时候，我还在医院库库修机器，修到一半，我停下来查了成绩，知道成绩之后就趁着一切空闲时间，选起了学校和专业。

中间还和豆包交流了不少时间，该说不说，豆包在这方面懂的东西还是不少。

但问题在于，现实真是太残酷了。485 分以下都上不了高中。

而在职业中学这个选择里，分数也代表了很多的东西，350 分是一个分水岭，在这个分数之上的，基本选学校和专业都比较方便，350 以下、320 以上，也还有一定的操作空间，类似于 3+2 这种学制还有余地。

但是 320 分以下，就很尴尬，也就是我弟这个分数。

今天上午我问了五六家学校，都是在成都市内口碑比较好的学校，其中要么就是招满了，要么就是分数达不到要求。

最后实在是没招了，因为很多学校在年初的时候就开始招生了，到现在出分这个时间点，基本上该敲定的都已经敲定好了。

不过还好，我两个月前在一所学校做过预报名，于是今天就拨去电话，问对方是否还需要到现场去报名，对方说要。

于是我便让我母亲带我弟去学校现场，但没想到的是，学校说 320 分之下的学生明天下午再去学校。

而明天会发生什么，目前来说，都不知道。

不过还好，其实最后最差的结局也就是上一个最普通的专科升学班，这其实也没什么不好。

只是这次中考找学校的经历，让我切身感受到了这个节骨眼上的兵荒马乱。

不仅是成绩好的学生有竞争，成绩差的学生同样要分三六九等。

成绩重要，抓住时机同样也很重要，有些学生提前几个月就开始找学校，最后也许成绩不那么理想，但同样能获得一个名额。
