# 标签分类与 Markdown 脚注修复设计

## 目标

修复文章列表的“分类”视图，并让迁移文章中的 Markdown 脚注正常显示和跳转。

## 分类行为

- “分类”视图以文章现有 `tags` 为数据源，不再使用当前为空的单值 `category`。
- 一篇文章有多个标签时，同时出现在多个分类组中。
- 每个分类组内部继续按文章日期降序排列。
- 没有任何标签的文章归入“未分类”。
- 分类顺序使用稳定的中文排序，不依赖当前为空的 `categories.json`。
- 年、月、周、日视图和文章列表上的标签展示保持不变。
- 本次不修改 160 篇文章的 `config.json` 或 Markdown。

分类分组应提取为纯函数，使多标签、多组排序和无标签回退可以独立测试。编辑模式现有的单值 `category` 管理不在本次扩展；公开“分类”视图明确表示标签分类。

## 脚注行为

采用与当前 `marked` 版本兼容的脚注扩展，不手写第二套 Markdown 解析器。渲染器必须支持：

- 正文中的 `[^id]` 生成可点击的上标引用。
- 文末 `[^id]: 内容` 生成脚注列表。
- 点击上标跳到对应脚注。
- 脚注提供返回正文引用位置的链接。
- 数字和文本脚注标识均可使用。
- 脚注内容继续支持链接、粗体等行内 Markdown。
- 现有标题目录、数学公式、代码高亮和图片组件行为保持不变。

在文章样式中为脚注上标、脚注区、列表和返回链接增加与当前排版一致的轻量样式。

## 测试与验收

### 自动化测试

- 分类：验证多标签文章进入多个分类、无标签文章进入“未分类”、每组日期降序。
- 脚注：验证输出包含正文上标链接、脚注列表、目标锚点和返回链接，且不再残留脚注定义文本。
- 回归：验证普通 Markdown 标题和段落仍能渲染。

### 项目验证

- 运行新增测试。
- 运行 TypeScript 检查。
- 运行生产构建。

### 线上验收

- 多标签文章可在对应多个分类组中找到。
